DeskNest 桌面巢 - 使用说明
================================

【运行要求】
- Windows 10 1809+ / Windows 11（64 位）
- WebView2 Runtime（Windows 11 自带；如缺失请安装包内 WebView2Runtime安装器.exe）

【快速开始】
1. 将 DeskNest 文件夹解压到任意固定位置（建议 D://DeskNest，勿放临时目录）
2. 双击 DeskNest.exe 启动（首次启动自动扫描桌面并按规则自动分类）
3. 坞条常驻屏幕顶部：鼠标移到屏幕顶边自动呼出，移开约 1.5 秒自动收起
4. 开机自启：右键坞条空白处 → 设置 → 开机自启
   （开启后每次启动自动核对注册表登记并自动修复，无需手动维护）

【功能一览】
- 自动分类：桌面图标按规则归入 办公 / 社交通讯 / 系统工具 / 设计创作 / 娱乐 / 其他
  （手动拖动过的条目永远保留用户选择，不被自动规则改动）
- 分类面板：悬停分类芯片展开面板；面板内可拖拽排序、拖到其他分类芯片完成重分类
- 右键菜单（条目）：打开 / 管理员运行 / 打开所在位置 / 属性 / 重命名 / 移动到分类 /
  新建分类并移入 / 取消手动归类 / 删除图标 / 刷新桌面 / 设置
- 删除图标：从分类中移除，同时把电脑上的实体文件删除到系统回收站（可恢复）。
  .lnk 快捷方式删除的是快捷方式本身；从回收站还原文件后重新拖入分类即可再归类
- 回收站（其他分类）：自动显示 满/空 两种状态并动态刷新；右键支持「清空回收站」
  （含项目数确认，永久删除前需二次确认）
- 此电脑（其他分类）：一键打开资源管理器"此电脑"
- 失效图标处理：目标文件被删除/移动后点击图标会弹确认框，可选择从分类中移除
- OS 拖放归类：把桌面文件/快捷方式直接拖到分类芯片即可归类（重复拖拽同文件 = 移动）
- 快速搜索：点击坞条搜索图标按名称过滤启动
- 全局热键：Ctrl+Alt+D 呼出/隐藏坞条（被占用时自动回退 Ctrl+Alt+R）
- 书签：管理常用网址，支持文件夹/置顶/网站图标，可导入导出（JSON/HTML/CSV）
- 书签搜索：管理器顶部搜索框输入关键字即时过滤（含文件夹内条目），找书签不用翻
- 书签浏览器同步：管理器顶部「同步 Edge / 同步 Chrome / 自选浏览器」读取浏览器书签
  合并到本地（同步前自动备份，同名不同址逐条确认，绝不静默覆盖）
- 书签删除同步：删除的书签网址会记入删除名单，之后同步浏览器或导入文件时
  不再重新加入 —— 删除一次即永久删除，不会被同步"复活"
- 镜像同步（全自动）：书签管理器顶部「镜像:开/关」（默认关）。开启后以浏览器为准，
  且无需任何手动操作：后台每 10 秒监听 Chrome/Edge 书签文件，浏览器里增删书签，
  约 10 秒内自动同步到本地（删除跟随会弹窗列清单；仅删除/冲突才弹窗，其余静默）；
  浏览器里重新出现的书签会加回并自动解除删除名单。
  安全护栏：单次清理超过 40 条时自动中止并提示，防止批量误删
- 删除写回浏览器（镜像开时自动生效）：在桌面巢删除书签 → 该网址自动从
  Chrome/Edge 书签中删除，无需手动去浏览器删。浏览器运行中会先排队，
  全部关闭后自动执行（写回前自动备份浏览器书签文件，保留 5 份）；
  下次打开浏览器时 Chrome/Edge 同步会把删除传播到你的账号所有设备
- 黑名单自动解锁：进入删除名单的网址，只要重新添加（手动添加、或浏览器
  里重新收藏后同步），会自动从名单解除，无需任何手动管理
- 全屏不干扰：全屏应用（游戏/放映）在前台时，鼠标移到坞条区域不会误触发呼出；
  快捷键呼出不受影响

【反馈与赞助】
- 设置面板底部提供「✉ 反馈 / 提需求」与「♡ 请我喝杯咖啡」入口
  （点击后打开浏览器中的反馈问卷 / 赞助页面）

【匿名使用统计（可关闭）】
- 软件每天最多一次向开发者发送一条极简的匿名计数信息，仅含 6 个字段：
  · install_id  首次启动生成的随机 UUID（持久化，用于去重计数）
  · version     软件版本号
  · lang        系统界面语言（如 zh-CN）
  · first_seen  首次启动日期（仅日期，不含时间）
  · autostart   是否开启开机自启（0/1）
  · timestamp   本次上报时间戳
  不含任何个人信息、不采集浏览记录、不采集文件路径与内容
- 用途仅为统计"大约有多少人在用、什么版本、什么语言环境"，帮助决定更新与维护投入
- 设置面板 →「统计」→ 关，即可完全停用；停用后不再发送任何网络请求

【退出程序】
右键坞条空白处 → 退出程序

【卸载】
双击程序目录里的「uninst.exe」——确认后自动完成：退出程序、清理开机自启登记、
删除整个 DeskNest 文件夹（含数据与备份），全程无残留。

【数据自动备份（v1.39.6 起）】
- 每次启动自动把 data\ 里的全部 json（分类/配置/书签等）滚动备份到
  data\backup\1 ~ backup\5（保留最近 5 份，越新编号越小）
- 数据异常时恢复：把 backup\1 里的 json 复制回 data\ 根目录覆盖，重启程序
- 手动整理的分类成果再也不会因为意外损坏而丢掉

【数据与配置】
- 分类、配置保存在程序目录的 data\ 子文件夹内（categories.json / config.json 等）
- 卸载仅需删除程序目录（数据随程序走，无隐藏目录）
- 卸载仅需删除程序目录与上述数据目录

【数据便携化】
- 全部数据（分类/设置/书签/重命名/日志）保存在程序目录的 data\ 子文件夹内，
  随程序移动；整个 DeskNest 文件夹拷贝到其他电脑/其他目录即可完整使用，无需重新配置
- 重装 C 盘系统不影响安装于非系统盘的 DeskNest 及其全部数据
- 开机自启为唯一例外（系统机制需在注册表登记一行程序路径）：
  v1.38.7 起支持启动自动修复 —— 整个文件夹拷贝到新电脑后首次运行会自动
  登记开机自启；即使登记项被安全软件清理，下次启动也会自动恢复。
  设置里的开关是唯一事实来源：显示"开"就一定会生效
- 旧版本升级：首次启动会自动把 %APPDATA%\DeskNest 的旧数据迁移到 data\，无需手动处理

【注意事项】
- 如被安全软件（360 等）拦截启动或文件操作，请将 DeskNest.exe 加入白名单
- 运行中更改显示缩放比例后建议重启应用
